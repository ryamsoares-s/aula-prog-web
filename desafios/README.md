# Lista de Desafios: HTML e CSS

Resoluções dos cinco desafios da lista de Programação Web (4º semestre).
Cada desafio está em sua própria pasta, com um `index.html` na raiz da pasta.

| Pasta | Desafio | Nível | Como o CSS foi aplicado |
| --- | --- | --- | --- |
| [desafio1](desafio1/) | Cartão de perfil | Fácil | Tag `<style>` no `<head>` |
| [desafio2](desafio2/) | Página de receita | Fácil | Arquivo externo `estilo.css` |
| [desafio3](desafio3/) | Card de produto com botão | Médio | Arquivo externo `estilo.css` |
| [desafio4](desafio4/) | Galeria de fotos | Médio | Arquivo externo `estilo.css` |
| [desafio5](desafio5/) | Mini landing page | Difícil | Arquivo externo `estilo.css` |

As três formas de aplicar CSS estão comentadas no topo de `desafio1/index.html`.

## O que cada desafio pratica

**Desafio 1 — Cartão de perfil**
`<h1>`, `<img>`, `<p>` e `<a>`; `background-color`, `color`, `text-align: center`
e `font-family`.

**Desafio 2 — Página de receita**
`<h1>`/`<h2>`, `<ul>` para os ingredientes e `<ol>` para os passos numerados;
`font-size`, `line-height`, `margin` e `padding`.

**Desafio 3 — Card de produto com botão**
`<img>`, `<h2>`, `<p>` e `<button>`; `padding`, `border`, `border-radius`,
`box-shadow` e o seletor `:hover`.

**Desafio 4 — Galeria de fotos**
Um contêiner `<div>` com quatro imagens legendadas; `display: flex`, `gap`,
`justify-content` e `width`.

**Desafio 5 — Mini landing page**
`<header>`/`<nav>`, área de destaque, `<section>` com 3 cards e `<footer>`;
Flexbox no menu horizontal e nos cards, botão estilizado e rodapé centralizado.

## Como visualizar

Abra o arquivo `index.html` de qualquer pasta direto no navegador — não é
preciso servidor. Pelo terminal:

```bash
xdg-open desafios/desafio1/index.html   # Linux
start desafios\desafio1\index.html      # Windows
```
